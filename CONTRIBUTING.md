# Contributing

Thank you for helping with HackintoiOS.

## Research quality

- Cite primary or otherwise reliable sources for technical claims.
- State whether a claim is verified, partially verified, a hypothesis, or unknown.
- Identify the exact device variant and hardware revision when known.
- Do not generalize from another Moto G60 variant or another phone.
- Keep notes reproducible and explain how conclusions were reached.

## Code and licensing

- Submit original work or code whose license permits the intended use.
- Preserve upstream copyright notices and license files.
- Do not add proprietary Apple source, firmware, extracted IPSW contents, signing material, or credentials.
- Include third-party provenance and license information for dependencies.

## Pull requests

- Explain the problem and the proposed change.
- List files changed and any sources consulted.
- State what was tested. Do not claim device support based on host-only checks.
- Keep changes focused and update the relevant documentation.

## Scope

The project is currently research-only. Contributions must not describe non-existent features as working or present unverified binaries as safe to install.
