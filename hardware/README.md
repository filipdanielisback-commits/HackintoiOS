# Hardware compatibility research

Track each component separately. Do not mark a component as supported based only on the fact that it works under Android.

| Subsystem | Evidence required | Status |
| --- | --- | --- |
| CPU / SMP | SoC documentation and architecture details | Unknown |
| GPU | Exact GPU identifier and public driver information | Unknown |
| Wi-Fi / Bluetooth | Chipset identifier and interface documentation | Unknown |
| Audio | Codec and routing documentation | Unknown |
| Camera | Sensor and ISP documentation | Unknown |
| Storage | Controller and protocol details | Unknown |
| Display / touch | Panel and touch-controller identifiers | Unknown |
| Power / battery | PMIC and charging architecture | Unknown |
| Haptics / sensors | Controller identifiers and interface details | Unknown |

Use the labels Verified, Partially verified, Hypothesis, or Unknown consistently. Include source links and variant details.
