# Security policy

HackintoiOS is an experimental research repository and does not currently provide a device-installable operating system.

## Reporting

For a security concern in this repository, open a GitHub issue without including personal data, credentials, private keys, or proprietary firmware. If a report could expose sensitive information, contact the repository maintainer privately through GitHub.

## Safe handling

- Do not publish signing keys, passwords, tokens, account data, or private device logs.
- Do not test unverified images on a primary or personal device.
- Do not bypass device security controls as part of this project's current research scope.
- Treat third-party binaries and firmware as untrusted unless their origin and integrity are established.
