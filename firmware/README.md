# Firmware research

This directory contains documentation only.

Do not commit proprietary firmware, IPSW files, extracted Apple system images, signing keys, credentials, or other material unless redistribution rights are explicit and documented.

## Current status

No firmware is included, downloaded, extracted, modified, or packaged by this project.

Research notes should identify the firmware component, its owner, license or redistribution terms, and the reason it is relevant. Prefer public documentation over redistributing binary blobs.
