# Bluetooth drivers

This directory is reserved for original Bluetooth transport and controller support.

Current status: research only. The HANOIP device tree contains a QCA WCN3990 Bluetooth-side description, but that does not establish the Wi-Fi chipset or prove the complete Bluetooth transport and firmware configuration for this exact XT2135-2 unit.

Keep Bluetooth evidence separate from Wi-Fi evidence. Do not infer shared silicon, bus topology, firmware names, or GPIO sequences without sources.
