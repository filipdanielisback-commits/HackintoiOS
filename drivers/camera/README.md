# Camera drivers

This directory is reserved for original camera sensor, camera-interface, and image-signal-processing support.

Current status: not implemented. Exact sensor models, camera module variants, CSI lanes, I2C addresses, regulators, clocks, reset sequences, and ISP interfaces remain to be verified for the target board.

Do not add vendor firmware, calibration data, or guessed sensor configurations. Begin with a source-backed inventory and synthetic parsers/tests.
