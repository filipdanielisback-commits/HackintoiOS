# Motorola HANOIP board layer

This directory is reserved for board-specific glue that is genuinely unique to the HANOIP family.

Keep generic Qualcomm SM7150-family support separate from HANOIP board configuration. The exact EVT/DVT overlay corresponding to the XT2135-2 retail unit remains unresolved, so board-specific runtime values must stay unset until verified.

Current status: documentation scaffold only; no board initialization code.
