# Device ports

This directory contains device-specific research and configuration for HackintoiOS.

## Current target

- [Moto G60 (XT2135-2)](moto-g60-xt2135-2/README.md) — research scaffold only; not yet a supported or bootable device.

A device directory is not evidence of hardware support. Each port must record verified hardware identifiers, boot-chain constraints, device-tree provenance, required drivers, and test results before claiming support.
